PI —— 桌面音乐应用（安装版）
========================================

怎么启动
--------
  · 开始菜单 → PI
  · 桌面上的「PI」快捷方式
  · 或者直接双击安装目录里的 pi.exe

  安装目录：%LOCALAPPDATA%\Programs\PI（每用户安装，不需要管理员权限）

怎么卸载
--------
  设置 → 应用 → 已安装的应用（旧版系统叫「应用和功能」）→ 找到 PI → 卸载。

  这会删掉程序文件、桌面与开始菜单的快捷方式，以及注册表里的登记项。
  也可以直接双击安装目录里的「卸载 PI.exe」，效果一样。

  注意：卸载**不会**删除你的数据。曲库缓存、设置、登录状态都放在
  %APPDATA%\PI，需要彻底清理时请手动删除那个目录。

数据放在哪
----------
  · 程序：%LOCALAPPDATA%\Programs\PI
  · 数据：%APPDATA%\PI

  数据不跟程序放一起，所以升级或重装程序不会丢数据。

没网也能用吗
------------
  可以。安装包里已经带了 Electron 运行时和全部依赖，不需要联网、
  也不需要预先装 Node.js。

  在线音源当然要有网才能取到歌；本地文件不受影响。

出问题了
--------
  · 启动没反应：先看 %APPDATA%\PI 下的日志文件。
  · 提示缺少 DLL：多半是杀毒软件隔离了文件，把安装目录加进白名单再重装。
  · 想换目录：重新运行安装包，在「选择安装位置」那一步改。

这个目录里还有什么
------------------
  · uninstall-helper.ps1 / 卸载 PI.cmd —— 便携版的卸载脚本，安装版留着它
    只是为了卸载时做延迟清理（Windows 不允许卸载器删除正在运行的自己）。
  · resources\ —— Electron 的运行时与 PI 的程序本体，不要手动改动。
